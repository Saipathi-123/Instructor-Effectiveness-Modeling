# Instructor Effectiveness Modeling

## Overview

This project analyzes instructor effectiveness in an EdTech environment using batch-level learner outcomes, engagement metrics, and feedback data.

## Objective

The objective is to:

- Perform exploratory data analysis
- Define an Instructor Effectiveness Score
- Aggregate batch-level data to instructor level
- Create effectiveness tiers
- Build a classical machine learning model
- Evaluate and interpret the model
- Discuss limitations and real-world applications

## Dataset

The dataset contains course-batch-level information including:

- Learner outcomes
- Engagement metrics
- Feedback metrics
- Instructor and course identifiers
